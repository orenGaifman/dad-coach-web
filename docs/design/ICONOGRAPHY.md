# Iconography

## Why Icons Matter

Icons provide instant orientation. In an interface designed for tired fathers with limited attention, icons reduce the time between intention and action. They must be immediately recognizable without being distracting.

## Emotional Intent

### Should Create

- Instant clarity
- Subtle warmth
- Consistency and reliability
- Sense of familiar territory

### Should Avoid

- Playfulness or cuteness
- Complexity requiring interpretation
- Inconsistency across the system
- Decorative noise without function
- Childish or cartoonish quality

## Icon Style

### Character

- **Outline style** with consistent stroke weight — not filled, not dual-tone
- **Rounded corners** on strokes — softer than sharp, warmer than geometric
- **Minimal detail** — every stroke must earn its place
- **Optically balanced** — icons should feel even at small sizes

### Size and Weight

- Stroke weight consistent across the set (1.5–2px at standard display size)
- Icons designed for a primary size but must remain legible one step smaller
- No icons that require large display to be understood

### Grid and Consistency

- All icons built on a consistent grid
- Consistent padding within bounding box
- Visual weight balanced across the set (a complex icon shouldn't feel heavier than a simple one)

## Principles

### 1. Function First

Every icon must serve a clear navigational or semantic purpose. Decorative icons are not used. If text alone is clearer, text wins.

### 2. Universal Recognition

Prefer universally understood metaphors. Avoid culturally specific or ambiguous symbols. A father should never pause to interpret an icon.

### 3. Warmth Through Softness

Rounded joins and terminals add warmth without making icons feel childish. The difference is subtle but important — soft, not bubbly.

### 4. Restraint in Quantity

Fewer icons, used consistently, is better than many icons used once. The icon vocabulary should be small and memorable.

### 5. Accessible Contrast

Icons always meet contrast requirements against their background. They are never the sole communicator of meaning — always paired with labels or context where accessibility requires it.

## Usage Categories

- **Navigation** — persistent, familiar, repeated (home, progress, coaching, profile)
- **Actions** — clear intent (send, save, close, expand)
- **Status** — belt progression, completion states, coaching state
- **Content type** — coaching topic indicators, child age signals

## What We Don't Use

- Filled/solid icon variants as default
- Animated icons in navigation
- Emoji as functional icons
- Brand-specific icons that require learning
- Icons smaller than comfortable tap targets
