# docs/design

## Purpose

This folder defines the visual identity and design strategy for Dad Coach. It translates the product values and brand principles (defined in [docs/brand](../brand/README.md)) into concrete visual decisions.

These documents guide all future design and implementation work. They define *what* and *why* — not *how* to implement.

## Design Emotional Summary

Dad Coach should feel: **calm, premium, trustworthy, modern, warm, focused.**

Dad Coach should never feel: childish, game-like, corporate, medical, overwhelming, overly masculine, or like productivity software.
