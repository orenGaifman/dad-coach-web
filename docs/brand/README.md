# docs/brand

## Purpose

This folder contains the product foundation documentation for Dad Coach — the single source of truth for product identity, brand, audience understanding, and strategic direction.

## Reading Order

For someone new to the project, the recommended reading order is:

1. PRODUCT → MISSION → VISION → NORTH_STAR
2. VALUES → BRAND_PRINCIPLES → DESIGN_PHILOSOPHY
3. TARGET_AUDIENCE → PERSONAS
4. AI_PHILOSOPHY → TONE_OF_VOICE
5. ANTI_GOALS (as a guardrail reference)
